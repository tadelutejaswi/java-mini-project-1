# 🎮 Java Mini Project 1 – Number Guessing Game

This is a simple **console-based Java mini project** where the user has to guess a randomly generated number between 1 and 100. It's a great beginner-friendly project to understand conditional logic, loops, user input, and random number generation in Java.

---

## 🚀 Features

- Random number generation between 1 and 100
- Interactive console prompts
- Feedback for each guess (too high / too low)
- Ends when the correct number is guessed
